HR · Project 6

Workforce Capacity & Skill Gap

Problem

Enough employees on paper, yet deadlines are missed because the right skills are unavailable at the right time. Map skills to demand, find critical gaps and recommend hire / train / reallocate.

Algorithm flow

InputProcessDecisionOutput
Load employee skill inventory + proficiency, project demand plan by week
Build skill-supply matrix (FTE-hours per skill per week)
Build skill-demand matrix from project pipeline
Gap = demand − supply (per skill, per week)
Gap > 0 ?
Can bench staff be reallocated (adjacent skill)? → reallocate
Else can staff be upskilled within lead time? → train
Else → hire / contract
Gap heatmap + action plan with cost & timing

Pseudocode

supply[s] = sum(e.hours * e.prof[s] for e in employees if s in e.skills)
demand[s] = sum(p.hours_needed[s] for p in projects if p.active)
for s in skills:
    gap = demand[s] - supply[s]
    if gap <= 0: continue
    gap -= reallocate(s, bench_pool)        # cheapest, fastest
    if gap > 0 and lead_time_ok(train): gap -= train(s, adjacent_skill_holders)
    if gap > 0: hire(s, ceil(gap / FTE_HOURS))
